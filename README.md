## 📖 О проекте

Это компиляция Homigrad, взятая из [**Steam аддона**](https://steamcommunity.com/sharedfiles/filedetails/?id=3324663643), созданного **Целазом**.

### ❓ Зачем это?

Сборка переложена на GitHub, так как многие хотят именно саму сборку в виде кода, а не готовый режим без исходников.

### 🔧 Что это такое?

**Homigrad CE1AZZ** — это форк **Homigrad-Original** от SadSalat'а с множеством изменений и улучшений:

**Переработанный интерфейс**
**Новые фичи и функции**
**Админ-панель для управления режимами**
**Админ-ганы и другие админ-инструменты**
**Множество оптимизаций и исправлений**
